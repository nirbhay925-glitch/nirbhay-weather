# 🌤️ Atmosphere Live - Weather Forecasting Dashboard

A responsive weather forecasting web application designed with modern glassmorphism aesthetics and real-time meteorological metrics.

## 🚀 Live Demo
🔗 [View Live Application](https://nirbhay925-glitch.github.io/nirbhay-weather/)

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Glassmorphic UI & Canvas Animations), Vanilla JavaScript
- **API:** OpenWeatherMap REST API
- **Deployment & Version Control:** Git, GitHub Pages

## ✨ Features
- Real-time temperature and atmospheric conditions
- 5-Day predictive weather outlook
- Humidity, Wind Speed, Visibility, and Barometric Pressure metrics
- Dynamic unit switcher (°C / °F)
- GPS geolocation lookup & global city search
